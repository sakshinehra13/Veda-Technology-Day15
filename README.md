# 💎 Pro POS & Shopping Bill Generator (INR)

A feature-rich, high-impact Point of Sale (POS) and itemized billing application built using **Python** and **Streamlit**. Designed specifically for Indian retail environments with real-time **INR (Rs.)** currency formatting, GST calculation, discount handling, and strict mobile number validation.

## 🚀 Key Features
* **⚡ Quick Catalog:** Instantly add pre-loaded items (Electronics, Stationery, etc.) with a single click.
* **📦 Custom Product Entry:** Add custom products with dynamic quantity and price adjustments.
* **📱 10-Digit Mobile Number Validation:** Strict validation ensuring customer mobile numbers are exactly 10 digits.
* **🏷️ Tax & Discounts:** Real-time calculation of custom discount percentages and GST rates.
* **📄 Live Thermal Invoice Preview:** Renders an authentic cash-register style receipt dynamically on the fly.
* **📊 Transaction Archive:** Log completed orders and search past transaction history by customer name.

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (Web Framework for Interactive UI)
